## [Weather dashboard](https://nafih-kc.github.io/Weather-dashboard/) 👈 (live click)

A simple dashboard that provides current weather conditions and a 5-day forecast for any city. Built with HTML, CSS, and vanilla JavaScript using a public weather API.

![Weather Dashboard](Weather%20Dashboard%20Tech%20Workspace.png)

## Live Demo works on any screen ratio..



## Overview

This project demonstrates front-end development fundamentals, including asynchronous API requests, dynamic DOM updates, and responsive layout design. Users can search for a city and instantly view its current weather along with the forecast for the coming days.

## Features

- City search with real-time weather data
- Current temperature, humidity, wind speed, and weather conditions
- last 5-day forecast history
- Responsive layout for mobile, tablet, and desktop
- Lightweight implementation with no external frameworks

## Technologies

- HTML5
- CSS
- JavaScript
- OpenWeatherMap API

## Usage

Enter a city name in the search field and submit. The application displays the current weather and the 5-day forecast for that location.
